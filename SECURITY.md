# Security policy

## Reporting a problem

Report security problems privately through [GitHub private vulnerability reporting](https://github.com/vanhoangkha/aws-saa-c03-study-guide-/security/advisories/new). Do not open a public issue.

Report:

- a security weakness in the simulator, the study site or the scripts;
- a malicious or hijacked link;
- guidance in the study material that would leave an AWS account insecure if followed, such as an over-permissive policy presented as good practice.

Include the file and section, what the problem is, and how it could be misused. You will get an answer within 7 days.

## Out of scope

- Security of AWS services. Report those to AWS through the [AWS Vulnerability Reporting](https://aws.amazon.com/security/vulnerability-reporting/) page.
- Third-party sites linked from the guide.

## Examples in this repository

Policies, commands and templates here are teaching examples. Account IDs, ARNs and keys are placeholders. Review any example against the [AWS documentation](https://docs.aws.amazon.com/) and apply least privilege before you use it.
